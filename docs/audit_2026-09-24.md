## 1. 水力學與水量守恆（AUD-1）

**水量帳（t = 142 s，dripper off）**

| 項目 | 模型 | 量測 |
|---|---|---|
| V_in | 302.7 mL | 302.1 g |
| V_out | 272.9 mL | 250.0 mL |
| 保水 | 30.2 mL | 52.1 g |
| Gagné LRR | 1.65 mL/g | 2.78 mL/g（V60 典型 2.2） |

缺口 21.85 mL ≈ φ·V_bed = 20.79 mL。根因：儲水方程 `dh=(Q_in_free−Q_out)/A(h)` 以孔隙率 1 的圓錐追蹤總水量，
沒有床內孔隙水的保水機制；h 在 t≈128 s 後卡在數值下限 H_MIN（28.8% 模擬時間），並由 clamp 憑空產生 0.48 mL。
Young-Laplace 估算的床層保水頭（r_pore≈0.2·d32）為 44–221 mm，遠大於 h_bed=53 mm，即濕床物理上無法被重力排乾。

吸水沒有狀態變數：流動方程扣除 ∫Q_in(1−sat_flow)dt = 28.75 mL（超過 V_full = 24 mL），
sat ODE 記帳 13.2 mL，差額 15.5 mL 無歸屬。

其他：床內儲水截面應為 φ_eff·A(h)（現用 A(h)，三套液體庫存互不一致）；q_extract 用固定 A_ref
而非截斷錐串聯阻力（R_true/R_model 1.65–4.3×，出水口內徑未量測）；bypass 在此基準佔 0.03%（h_free 從未超過 3.5 mm；
真實自由水頭約 17 mm）；`retained_mass_g` 欄位全 repo 零引用。

實驗證明修正可行：加入 20.79 mL hold-up 並將 k×1.2，V_RMSE 由 13.80 降到 13.07 mL，末段殘差 +23 → +2 mL，LRR 2.67。
但三次振盪殘差（−18.7/+22.4/−14.8/+23.8 mL）與守恆問題正交，修守恆不會消除它。

## 2. 熱模型（AUD-2）

- `core.py` 液體節點註解宣稱 dV_eff/dt = Q_in_free − Q_out，實測比值恆為 φ = 0.4000；被漏掉的 (1−φ)·T·(…)/V_eff
  項時序量級 ±25–120 K/s，保留的對流/交換項僅 ±1–2 K/s（平均 44.6×）。累積能量殘差 −0.25% 看似通過，
  但參考溫度不變性破壞（T_ref=0 K 與 T_amb 殘差差 0.96% E_in），證明逐點方程錯誤。
- 被吸收的 29.2 mL 熱水（8.4 kJ = 10.7% 輸入能量）既不進熱容也不帶焓。凍結水力學補回後，
  悶蒸期出水溫度對量測的 RMSE 由 17.2 降到 8.4 °C（t=5 s：53 → 70.9 °C，量測 70.8）。
- 擬合的 `lambda_liquid_dripper = 0.0496 /s` 隱含 U = 1044 W/(m²K)（bloom 期 16000），
  濕濾紙+陶瓷串聯的絕對上界為 546、名目 194。它同時在補償 2.5× 的熱容缺口與吸收水缺口。
- 兩個 λ 擬合單一杯溫純量：cup_error=0 等值線橫跨 λ_liq 13×、λ_srv 42×。用 14 點 server 溫度時序即可收斂到
  λ_liq≈1.8e-2（落在物理區間），RMSE 2.70 → 1.68 °C。
- `thermal_profile.csv`（52 個溫度觀測點）全 repo 零引用，且與 `flow_profile.csv` 並非同一次沖煮（注水差最大 62 g）；
  outflow 探針語意在兩個 case 間不一致（t=5 s：70.8 vs 25.1 °C）。docs/superpowers 的熱時序計畫寫完即擱置、無紀錄。
- `MEASURED_VESSEL_EQUIV_ML = 42.4` 名為量測實為反推；server 質量未記錄；杯溫量測時刻未定義。

## 3. 萃取與 TDS（AUD-3）

- `internal_diffusion_factor_path` 的 `exp(−L²/4Dt)` 對 slow 主導 bin（70% 質量）整段 < 0.1（時間平均 0.083）；
  移除後 `nw_eta_slow` 由 118 降到 6.8。該因子 t→∞ 趨近 1（速率遞增），與 Crank 球形擴散（通量遞減）方向相反，
  且把 bin 間相對速率打亂（細 bin 快 4×、粗 bin 慢 45×）。40% 的 M_sol_0 在 180 s 內結構性不可達。
- Stage 7 用 (k_ext_slow, max_EY) 擬合單一 TDS：`max_EY` 與凍結的 `fast_fraction` 完全簡併（swing 6.3 vs 5.0 g/L），
  `k_ext_slow` swing 僅 0.55 g/L；fast pool 被榨乾 99.95%。`max_EY_fit = 0.3725` 超過任何文獻上限。
- TDS = M_extracted / V_out_model，而模型 V_out 高估 9.1%；以量測 250 mL 為分母 TDS = 12.63 g/L（+1.07），
  即 stage 7 吸收了水力誤差（CLAUDE.md §6 明文禁止）。
- 溫度相依三重計數（固定 mobility 的 D、Arrhenius、diff_factor 內的 D）：slow 對 80→95 °C 敏感度 2.33× vs
  Stokes-Einstein 1.25×。`Ea_slow`、`C_sat_*`、`alpha_C_*`、`k_diff_ratio`、`Q_half`、`nu_p_fast` 的 ±30% swing 全部低於
  量測不確定度（±0.69 g/L），不可辨識。slow pool 全程 kinetics-limited，C_sat 只是線性因子。
- `shell_thickness = 200 μm` 的絕對 floor 使 L_fast 在 6/7 bin 全等於 100 μm（fast 無 bin-resolution），bin0 出現 L_slow > R。
- 實測替代閉合：slow 改 Crank 首項一階釋放（λ_i = π²D/R_i²）後，達到 TDS 11.56 所需 `max_EY = 0.267`
  （配合保水修正為 0.244，M_sol_0/dose ≈ 20%），`nw_eta_slow` 參數消失，fast/slow 貢獻 59/41。
- TDS 量測不確定度：Brix 0.85 換算係數文獻範圍 0.79–0.89 → ±0.69 g/L；宣稱的 +0.015 g/L 是過擬合指標。

## 4. 目標函數與誤差計算（AUD-4）

- loss = 1.0·V_RMSE + 0.8·q_RMSE + 0.5·|Δt| + 0.35·|ΔT| + 0.6·|ΔTDS|，單位混雜。以量測 σ（V 3.0 mL、q 0.28 mL/s、
  stop 2.5 s、T 0.5 °C、TDS 0.72 g/L）正規化後：V 與 q 佔 χ² 的 100%，drain/temp/TDS 合計 0.002%
  （各有專屬自由參數可精確歸零 → 過參數化）。reduced χ² = 21。
- velocity 項：q_pred − q_obs 與 V 殘差差分在機器精度上相等，即對同一殘差的 H¹ 平滑度罰，非獨立觀測；它撐起 tau_lag=2.0
  （χ² 下塌到下界 0.5）。
- V 殘差 lag-1 自相關 0.914、Durbin-Watson 0.169、runs test z=−3.89；注水期 q 殘差 −0.14、靜置期 +0.35 mL/s。
  有效獨立樣本數 ≈ 1.4。「V_RMSE 5.06% < 7% gate」的驗收在統計上不成立。
- `phys_penalty` 區間與 optimizer bounds 相同 → 恆為 0（200 點驗證）；regularization 佔 loss 0.016% → PSD prior 零約束力，
  且 prior anchor 在 fit 與 reload 時為不同數（1436.6 / 1058.9 / 1350）。
- `fit_with_multi_start` warm-start 硬編碼 canonical summary；kinu27 與 kinu28 的 `k_fit` 在 16 位有效數字上相同
  （1.437025577808407e-10），cross-validation 不獨立。
- benchmark `rmse_relative` 分母用模型 v_out（272.8）而非量測（250）；誠實值 5.5%，含 t=135 列 5.7%。
  fit_mask 排除 t=135（殘差最大）卻納入 t=142（次大），而 stop time 取自被排除的列。
- Profile likelihood 95% CI：k ±13%（可識別）；k_beta 覆蓋全界（12×）；tau_lag 貼下界；max_EY 覆蓋全 envelope；
  λ_liq_drip ≥ 9.5×。
- Powell ftol=1e-2 為相對容差（絕對 ≈0.15），與 coarse/fine 離散偏差 0.069 同量級。

## 5. PSD 與資料處理（AUD-5）

- 原始 CSV 幾何恆等式（機器精度）：π·SHORT·LONG = SURFACE（兩軸為半軸，px）；ROUNDNESS ≡ SHORT/LONG；
  VOLUME = SURFACE×SHORT（偽 3D）；min(SURFACE) = 5 px²。
- `psd.py` 忽略 PIXEL_SCALE，寫死 /5、/10 等價假設 100 μm/px；管線自己輸出的 `hist_avg_diam_relerr_pct` 在四檔為 +54~67%。
  PIXEL_SCALE 單位為 **px/mm**（canonical 58.0 μm/px 為低倍率、per-case 27–29 μm/px 為高倍率），
  μm/px 讀法在 canonical 檔數學上不可能（最大顆粒 655 < 軟體平均 881 μm）。
- 正確尺度下五份掃描 Dv50 = 999 / 1166 / 1335 / 1216 / 1135 μm（k29top / k29-4:11 / k29-4:12 / k27 / k28），
  Sauter d32 = 835–1069 μm。同研磨度散布（17–34%）大於研磨度間差（7%），現有 PSD 無法解析 Kinu 一格。
  絕對標定殘留 ±45% 系統不確定度（stats CSV 反推值大 1.45×，原因未明）。
- number-based D10 = 整數像素格點（S=11 → 0.3742 mm；S=21 → 0.5171 mm）；偵測下限 canonical 146 μm、per-case 69–74 μm。
  `D10_measured_m` 被當 Class-A 量並用 `particle_scale` 縮放整條 PSD；`ref_particle` 由 `k_ref` 反推。
- `_load_psd_bin_rows` 縮放直徑但不重算 shell accessibility；`shell_thickness=200 μm` 在正確尺度下使 fast_pool_fraction
  0.87–0.99，雙 pool 退化。
- `k_beta_prior_from_psd`：prior ∝ k_beta 自身且 clip 在 0.45×k_beta（校準點正好卡下界）→ 循環 prior，零約束力。
- Option C dual-baseline 敘事方向相反（canonical 是低解析度；per-case fines 多 52–73%；「38%」= √(21/11)），
  override 選中的是讓 TDS 預測偏高的資料。

## 6. 數值、後處理與測試（AUD-6）

- RK45 rtol≤1e-6 已收斂；LSODA 可用且略快（註解相反）；rhs 內 h clamp 造成 ~0.05 mL 非單調地板。
- 後處理 `sat = np.where(t<t_bloom_end, sat_state, 1.0)` 展示值被餵回物理重算：q_* 偏 +0.19%、k_vals 局部 12.6%、
  負 bypass −0.45 mL；`v_extract_ml`/`v_in_ml` 重算而非用 ODE 狀態 V_bed/V_poured（n_eval=720 時 aliasing −1.17 mL）。
- `apply_outflow_lag` 顯式 Euler：tau_eff 偏 −6.4%（coarse）至 −28%（tau=0.5），且 tau 幾乎只由 stop time 識別。
- summary 的 `drain_time_error_s` 實為 cup-stop 誤差（+0.11 s）；`drain_time_s` 對量測差 −5.6 s。
- 唯一測試檢驗的是 telescoping 恆等式：k_ext_slow×100 使 TDS +30% 仍 PASS；無 pytest/CI。
- loss cache 存整個 sim（0.8 MB/entry）；cache key 絕對 rounding 在 λ_server 下界 margin 1.9×。
